เพิ่มไฟล์ HTML

เพิ่มไฟล์พร้อมชื่อ คำอธิบาย หมวดหมู่ และภาพปก เพื่อให้ค้นเจอง่ายในภายหลัง

ลากไฟล์มาวางไม่ได้ในทุกเบราว์เซอร์ — กดเลือกไฟล์ด้านล่าง
ไฟล์ตัวอย่างเดิมจะอยู่ในคลังให้แล้ว สามารถเพิ่มไฟล์ใหม่ภายหลังได้
ถ้าไม่ใส่ภาพปก ระบบสร้างปกให้โดยอัตโนมัติ สามารถใช้ภาพหน้าจอของเครื่องมือเป็นปกได้
คำอธิบายและแท็กช่วยให้ค้นไฟล์เจอเร็วขึ้น ข้อมูลทั้งหมดเก็บในเบราว์เซอร์นี้

ตัวอย่างไฟล์

แสดงตัวอย่างในพื้นที่แยก เพื่อไม่ให้โค้ดของไฟล์รบกวนหน้าคลัง

วิธีใช้คลัง HTML

เตรียมไฟล์ให้พร้อมใช้ซ้ำ ไม่ต้องไล่หาในโฟลเดอร์

1. เพิ่มไฟล์: กด “เพิ่มไฟล์ HTML” แล้วเลือกไฟล์ .html หรือ .htm ได้หลายไฟล์พร้อมกัน
2. ทำให้ค้นเจอง่าย: ตั้งชื่อที่เข้าใจง่าย ใส่คำอธิบาย หมวดหมู่ และแท็ก เช่น GPT Image, UI/UX, เครื่องมือภาพ
3. ดูตัวอย่าง: กด “ดูตัวอย่าง” เพื่อเปิดหน้า HTML ในกรอบแยก หรือกด “เปิดแท็บใหม่” หากต้องการทดสอบแบบเต็มหน้า
4. นำไปใช้: กด “ดาวน์โหลด” เพื่อรับไฟล์ .html กลับไปวางในโฟลเดอร์หรืออัปโหลดขึ้นเว็บโฮสต์
5. สำรองข้อมูล: กด “สำรองข้อมูล” เพื่อดาวน์โหลด JSON ที่มีทั้งเนื้อหา HTML และคำอธิบาย เมื่อใช้คอมพิวเตอร์เครื่องอื่น ให้เปิดคลังแล้วกด “นำเข้าข้อมูล”

หมายเหตุสำคัญ: ข้อมูลจัดเก็บในเบราว์เซอร์ของเครื่องนี้ ไม่ได้ซิงก์คลาวด์อัตโนมัติ ควรสำรองไฟล์ JSON เป็นระยะ และเก็บไฟล์คลังไว้ตำแหน่งเดิม
