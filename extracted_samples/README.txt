MIX-IMAGE HTML ARCHIVE
======================

เริ่มใช้งาน
1) แตกไฟล์ ZIP นี้ไว้ในโฟลเดอร์ที่ต้องการ
2) เปิด MIX-IMAGE-HTML-Archive.html ด้วย Google Chrome หรือ Microsoft Edge
3) คลังจะมีไฟล์ตัวอย่าง HTML 4 รายการให้ก่อน สามารถดูตัวอย่างหรือดาวน์โหลดไฟล์ได้ทันที
4) กด “เพิ่มไฟล์ HTML” เพื่อเพิ่มไฟล์ของคุณเอง และใส่คำอธิบาย/หมวดหมู่/แท็ก
5) ใช้ “สำรองข้อมูล” เพื่อดาวน์โหลดไฟล์ JSON ที่รวมเนื้อหา HTML และข้อมูลประกอบทั้งหมด

ข้อมูลจะจัดเก็บในเบราว์เซอร์ของเครื่องนี้ (IndexedDB) ไม่ได้อัปโหลดขึ้นคลาวด์โดยอัตโนมัติ
ควรเก็บไฟล์สำรอง JSON เป็นระยะ หากย้ายเครื่องหรือเปลี่ยนเบราว์เซอร์ ให้เปิดคลังแล้วกด “นำเข้าข้อมูล”

ไฟล์ตัวอย่างที่มาพร้อมแพ็ก
- STREET-RIDE-DRIFT.html
- StreetRideDrift.html (สำเนาเนื้อหาเดียวกันแต่ชื่อไฟล์ต่างกัน)
- index(3).html (เครื่องมือทำภาพหน้างานศพ)
- ตามหากันจนเจอ – พรอมต์ GPT Image 2.5 ชุดชิบิ 80 ภาพ.html
