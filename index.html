ย้ายข้อมูลสู่ Firebase Cloud (Migration Tool)

นำเข้าไฟล์ HTML เดิม และสำรองข้อมูล JSON จาก IndexedDB ขึ้นสู่คลาวด์อย่างปลอดภัย พร้อมตรวจจับไฟล์ซ้ำ (SHA-256)

เลือกไฟล์สำรองข้อมูล JSON (เช่น MIX-IMAGE-HTML-Archive-Backup-*.json) ที่เคยดาวน์โหลดไว้

เลือกไฟล์ .html ได้หลายไฟล์พร้อมกัน ระบบจะสกัด Metadata, คำนวณ SHA-256 และอัปโหลดขึ้น Storage

ระบบจะทำการนำเข้าไฟล์ตัวอย่างเริ่มต้น 4 รายการที่มาพร้อมแพ็กเกจ (STREET-RIDE-DRIFT, สำเนาสำหรับทดสอบไฟล์ซ้ำ, เครื่องมือทำภาพหน้างานศพ, และตามหากันจนเจอ ชิบิ 80 ภาพ) ขึ้นสู่ Firebase Cloud ของคุณโดยตรงในคลิกเดียว

💡 หมายเหตุ: ไฟล์ตัวอย่างจะถูกแฮช SHA-256 และอัปโหลดขึ้น Storage พร้อมจัดหมวดหมู่และแท็กให้อัตโนมัติ

เข้าสู่ระบบ MIX-IMAGE

เพื่อจัดการไฟล์ เพิ่ม ลบ และแก้ไขข้อมูลในคลังคลาวด์

วิธีใช้งานคลัง HTML Cloud Edition

คู่มือการใช้งานระบบคลาวด์เรียลไทม์

1. บันทึกและซิงก์เรียลไทม์: ทุกไฟล์ที่อัปโหลดจะถูกส่งขึ้น Google Cloud Storage และข้อมูลจะซิงก์ทันทีผ่าน Firestore บนทุกเครื่องที่เปิดหน้านี้อยู่

2. ตรวจจับไฟล์ซ้ำ (Deduplication): ระบบคำนวณ SHA-256 Hash ของไฟล์ HTML ก่อนอัปโหลด หากมีไฟล์เนื้อหาเหมือนกันจะแจ้งเตือน ป้องกันการกินพื้นที่ซ้ำซ้อน

3. ความปลอดภัยแซนด์บ็อกซ์ (Sandbox Preview): หน้าพรีวิวจะรันใน Iframe ที่แยก Origin ออกจากระบบหลัก ป้องกัน JavaScript ในไฟล์ HTML เข้าถึง Session หรือบัญชีของคุณ

4. ย้ายข้อมูลจากระบบเดิม: สามารถกดที่เมนู ย้าย/นำเข้าข้อมูล (Migrate) เพื่อนำไฟล์สำรอง JSON หรือไฟล์ HTML เดิมขึ้นสู่ระบบคลาวด์ได้ในคลิกเดียว
